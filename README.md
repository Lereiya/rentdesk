# SmartRent KE

Smart Property Management. Simple Tenant Living.

A modern, multi-tenant SaaS platform designed for Kenyan landlords, property managers, agents, caretakers, and tenants. It handles properties, units, rent, water bills, garbage charges, payments, arrears, maintenance requests, and property analytics.

## Tech Stack
- **Frontend:** React, Next.js, Tailwind CSS, shadcn/ui
- **Backend & Database:** Supabase (PostgreSQL, Auth, Storage, Realtime)
- **Integration Ready:** Safaricom M-Pesa Daraja API, Co-operative Bank, SMS/Email providers
